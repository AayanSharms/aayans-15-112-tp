PyPhoto Editor -- Generated by claude

PyPhoto Editor is a Python photo editor built as a CMU 15-112 term project. It loads an image through the OS file picker and lets you apply brightness, contrast, saturation, exposure, and temperature adjustments, a from-scratch separable Gaussian blur, and a freehand draw tool — all non-destructively, with full undo/redo. The image-processing math (convolution-based blur, brightness/contrast/saturation formulas) is implemented from scratch rather than through library calls; Pillow is used only for image I/O, and cmu_graphics for the window/canvas and UI events.

How to Run

Requirements

Python 3 (any modern 3.x version)
cmu_graphics — this project imports it from a local, unzipped copy of the course package placed in the project root (not installed via pip). If you don't have that copy, pip install cmu-graphics also works.
Pillow — pip install Pillow
tkinter (ships with most Python installs) — used only to show the native "Open Image" file-picker dialog

Setup

Put UI.py, pixel_image.py, convolution.py, and AdjustmentSidebar.py in the same folder.
Add an Images:Assets folder next to them containing:
foldericon.png
pointericon.png
bluricon.png
drawicon.png
Install Pillow (pip install Pillow) and make sure cmu_graphics is importable (see above).

Running

python UI.py

This opens a 1280x720 window. Click Open and pick an image (roughly 500x500 works best) in the file dialog that appears.

Basic usage once an image is loaded

Left toolbar: switch between the Select, Blur, and Draw tools.
Right sidebar: drag a slider for the active tool — it previews live and commits when you release the mouse.
Undo / Redo buttons (or u / r, see Shortcuts) step back/forward through committed edits.
Reset clears all edits back to the original image.
Libraries
cmu_graphics — window, canvas, and UI events
Pillow (PIL) — image loading and pixel buffer conversion
Standard library — tkinter, subprocess, sys, os, copy, math
Shortcut Commands
u — Undo the last committed edit
r — Redo the last undone edit

No other keyboard shortcuts exist yet (e.g. there's no key to auto-load a sample image, so testing goes through the file-picker each run).
